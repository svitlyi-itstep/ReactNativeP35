## Випадковий персонаж з Rick and Morty

Реалізувати екран, який виводить випадкового персонажа з серіалу "Рік та Морті".

- Дані отримувати з API [rickandmortyapi.com](https://rickandmortyapi.com/).
- Новий персонаж має з'являтися при відкритті екрана та при натисканні кнопки "Далі".
- Новий персонаж з'являється з fade-in і невеликим зсувом, а кнопка "Далі" робить пружинний стрибок при натисканні.
- Додати можливість **вказувати фільтри** (наприклад, статус, вид, стать) та очищувати фільтри.
- Додати **лічильник переглядів** — невелика статистика під карткою: скільки персонажів переглянуто за сесію та скільки з них живих і мертвих.

**Додатково:** реалізувати **історію переглянутих персонажів**. Під карткою — горизонтальний список останніх 5–10 персонажів, яких показувало. Тап на мініатюру повертає того персонажа без нового запиту, бо його дані вже є в кеші.


### Підказки щодо API

Список персонажів з фільтрами й пагінацією:

```
GET https://rickandmortyapi.com/api/character/?status=alive&species=human&page=3
```

Відповідь:

```json
{
  "info": { "count": 439, "pages": 22, "next": "...", "prev": null },
  "results": [ { "id": 1, "name": "Rick Sanchez", "status": "Alive", "species": "Human", "image": "..." } ]
}
```

Окремий персонаж за ідентифікатором:

```
GET https://rickandmortyapi.com/api/character/42
```

**Як отримати випадкового персонажа з урахуванням фільтрів.** Спочатку зробити запит із фільтрами, щоб дізнатися `info.count` і `info.pages`. Потім обчислити випадковий номер персонажа в межах `count`, визначити, на якій він сторінці та якою позицією в ній (за розміру сторінки 20 записів), і завантажити саме цю сторінку.
